## 本次实现

- 编译 x86 C++ `th20_native_bridge.dll`，提供七个随机数/计时器函数，保持原寄存器/栈调用约定。
- 新 `th20_rebuilt.exe` 保留原引擎入口和未恢复机器码；七个函数入口通过新增导入表调用 C++，新进程不会启动原 `th20.exe`。
- 保留原六节布局、211 个原 IAT 导入位置和 29,196 个原重定位；新增七个跳转操作数的重定位。原文件内仅 70 个字节改变，均为 PE 头字段和七个函数入口。
- 复制哈希一致的 `th20.dat`、`thbgm.dat` 和原设置工具；完整发布清单见 `playable_build.json`。

## 验证边界

这是可玩的混合增量重建，**不是整款游戏的完整纯 C++ 源码**。碰撞、敌机、弹幕、脚本 VM、绘制、音频、菜单、输入和回放主体目前仍由保留的原机器码承担。

共享回放帧号来自原引擎输入推进计数，不是状态更新完成屏障。两次相同的只读采样减少了撕裂风险，但不能替代锁步逐帧记录；未采到或不稳定的帧没有插值。尚未完成所有敌弹/实体、图像、音频、关卡、角色、难度与通关情况的等价性检查。

当前自动化按键没有被游戏稳定识别，因此不能把演示回放当作手动移动、射击、暂停的实操验收。没有为此更改原输入逻辑。

首选基址 `0x400000` 在硬件测试工具进程中被 Windows 代码页文件占用，所以该项明确记为跳过；两个非首选基址的重定位执行和真实 Windows ASLR 启动均已通过。浮点测试限于记录的本机硬件及控制环境。
