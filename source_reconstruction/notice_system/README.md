Entry points: ctor4dea60, dtor4deb80, initialize4df670, update4decf0, factory4dfb90. Object layout assertions include completion flag+90, distinct from Timer+14.

The original notice state0 substate0 immediately creates text and formats notice_XX.png; it does not launch an image read in that path. The separate original substate3 image upload and substate6/7 secondary animation paths are retained. All five original text completion wrappers are verified empty through46ebb0/46a4b0/40e5e0. The draw callback478bf0 literally returns1.

`pool_validation.json` records **59,904 passed, zero failed** original CPU comparisons. They include 256 whole constructor/destructor cases, 4,096 complete update calls, all25 message pairs, both outline flags, real GDI/queued texture pixels, seven ANM slots, cursor/input/timers/sound, and cache-hit load callback activation with owned scheduler-node destruction. This scoped test report is not full game completion or a 1:1 claim. Original message indexes outside0..24 are rejected instead of reading beyond the table.
