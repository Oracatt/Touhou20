# 共享随机数与时钟状态

`state.hpp/state.cpp` 恢复四个实际 28 字节 RNG 对象（原 5ba4a8、5ba4c4、5ba4e0、5ba4fc）、422c50 构造、422c00 种子归一化、4d9940 设置种子，以及 423ee0/423ea0/429830/4298e0 采样。它们与 ECL/ANM 使用同一状态引用及第 10 号共享递归锁，不维护重复的随机序列。

164,000 项隔离原 CPU 对照比较整个对象、返回位模式和四种浮点舍入模式。报告 `cpu_validation.json` 绑定实际源码哈希。默认上界与显式设种后的上界不同，按原数据保留；零模数在原程序触发除零，源码以异常显式拒绝该错误域。

`clock_scale`、`timer_rate` 分别恢复原 5aefe4/5aefe0 的初值和别名，4292a0 是直接修改缩放值。此模块不代表整个游戏 RNG 调用顺序已经逐帧验证。
