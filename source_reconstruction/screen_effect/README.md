# ScreenInf 屏幕效果源码

恢复原 `0x44` ScreenInf：十种效果模式、七个更新回调、四个绘制回调、`423650` 矩形绘制，以及构造、调度注册和销毁。背景过渡可直接调用 `create_effect`；生产库只执行 C++。

`cpu_validation.json` 记录 124,288 项原 CPU 对照：

- 七个更新回调各 4,096 组输入，比对完整对象、返回、整个 Graphics 状态和 RNG 状态。
- 十种模式共 640 组构造/初始化/析构，包括调度节点参数、顺序和解绑。只归一化已知 C++ 虚表和分配节点地址。
- 矩形核心及四个绘制回调各 320 组，比对全部顶点字节、COM 调用顺序与参数、受影响控制器字段和完整 Graphics 状态。

原 `4249f0` 的零 Y 震屏分支写 `camera[3].points[2][1]`，与其非零分支不同；源码按原指令保留，测试覆盖。随机方向仍使用共享第二个 RNG，保持调用次数。

测试的 DrawPrimitiveUP 为记录 COM 参数的边界，未声称 GPU 像素或完整场景过渡已验收。原模式范围外的空指针访问改为显式异常；有效模式为 0–9。内存分配失败的工厂分支未进行原 CPU 对照。

工程根的 `build_sources.ps1 -Validate` 会编译并运行此模块对照。
