# CardInf CPU evidence

`pool_validation.json` is regenerated by `../bullet_system/record_pool_evidence.py`
only after the shared Win32 oracle succeeds and every compiled input hash matches.
This group contains **206,784 original CPU comparisons, zero failures**. The
oracle maps the hash-checked original executable for tests only; production Card
code neither loads it nor calls its addresses.

| Original entry | Scope | Checks |
| --- | --- | ---: |
| 486bb0 / 486d20 | Complete constructor; real three-handle deletion | 1,536 |
| 487b10 / 486d20 | Actual scheduler registration and owned-node destruction | 448 |
| 488990 / 4885e0 | Encoded-time arithmetic and invalid-code predicate | 65,536 |
| 486f60 | Complete update, two contexts, timer/float boundaries | 57,344 |
| 487590 | Actual profile/card selection and text queue | 24,576 |
| 4878b0 | Capture result, real score/HUD/records/ANM/audio | 22,528 |
| 487c30 | Start, recursive child ANM, attempt records, queued title | 10,240 |
| 4872d0 | Post-frame quantization and recording/playback records | 24,576 |

Owned scheduler allocations and callback addresses differ between executables;
only those proven pointers are normalized, and all pointed-to node fields and
list topology are separately compared. No instructions are replaced or patched.
The clock tests substitute one deterministic OS sample at the import boundary;
the original 41cb10 and recovered clock arithmetic both execute.

The first timing run found 46 state/record mismatches in 23 cases. The original
543310/543320 converts to **signed 32-bit**, returning 0x80000000 for conversion
overflow. The first source incorrectly took the low word of a signed 64-bit
conversion. `timing_first_failure.json` preserves that failed run; the corrected
source passed all original inputs. Example elapsed -2147483649 produced original
encoded 2141833 versus former source 102106533; elapsed 4294967296 produced
12041832 versus 12006532.

Limits: start tests compare a real queued title task's count, not execution of its
GDI rasterization/completion. Portrait file selectors are -1. Finish tests omit
the all-113-captures achievement endpoint; entering it raises an explicit fixture
error. Replay records are isolated valid objects, without replay file IO. The ANM
programs are bounded synthetic inputs. This does not establish full gameplay or
pixel equivalence.

Reproduce with the commands documented in `../sprite_renderer/pool_test`, passing
the original hash-verified th20.exe and the shared JSON output, then run the
recorder. Test code is in the six `*_cpu_cases.inc` files in this directory.
